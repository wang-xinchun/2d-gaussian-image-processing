# Working with this repository

## Clone the public repository

```sh
git clone https://github.com/wang-xinchun/2d-gaussian-image-processing.git
cd 2d-gaussian-image-processing
```

See [README.md](README.md) for the project overview and repository layout.

## Contribute changes

1. Create a branch for your changes. If you do not have write access, fork the repository first.
2. Review your changes with `git diff` and run the checks relevant to your changes.
3. Open a pull request describing what changed and how you verified it.

Do not commit credentials, machine-specific configuration, or private infrastructure details.

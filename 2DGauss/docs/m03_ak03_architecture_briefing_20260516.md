# `M03/A_k03` 架构汇报说明

更新时间: `2026-05-16`

## 1. 文档目的

这份文档服务于**架构汇报**，对象是当前项目中已经冻结、已经被正式接受、并且可复现的最强里程碑：

- 里程碑: `M03`
- 对应实验: `V1/T01/A_k03`
- 任务: `UHD_deblur`
- 当前冻结 official baseline: `26.199959289578075 dB`

本文重点不在于罗列所有实验历史，而在于回答三个汇报场景里最关键的问题：

1. 我们这个架构到底在解决什么问题；
2. 我们的核心创新点为什么是**高斯**，而不是普通 CNN/Transformer 细节增强；
3. 这条高斯主线目前已经被验证到什么程度，边界又在哪里。

## 2. 一句话定位

我们的主线不是“再做一个更重的复原 backbone”，而是提出一种**面向超高清图像复原的跨分辨率 2D Gaussian 引导框架**：

> 在低分辨率空间中学习紧凑、可解释、纹理/频率感知的 2D Gaussian 参数场，再把这些结构化先验以高分辨率 attention 与低秩仿射调制的方式回注到高分辨率恢复过程中。

这条路线的目标是同时满足三件事：

1. 不在 full-resolution 上做代价极高的密集建模；
2. 不牺牲 UHD 图像最重要的边缘、纹理和高频细节；
3. 保持参数量和显存开销在可部署范围内。

## 3. 我们真正要解决的问题

超高清图像复原的核心矛盾不是“复原模型还不够深”，而是：

1. 分辨率极高，直接在原图尺度做 dense 建模成本太大。
2. 如果只做简单下采样建模，又会丢失最关键的高频细节。
3. 传统高分辨率 attention 或全局建模在 UHD 条件下很容易带来不可接受的显存和计算开销。

因此，我们不走两种极端：

- 不直接在原图分辨率上做大规模 dense attention。
- 也不接受“低分辨率做完再简单上采样回来”的粗糙方案。

我们的回答是一条中间路线：

> 低分辨率做紧凑参数化建模，高分辨率做结构化回注。

而这条中间路线的核心承载体，就是 2D Gaussian。

## 4. 为什么我们的创新点是高斯

### 4.1 高斯在这里不是“几何装饰”，而是结构化表示

我们引入 2D Gaussian，并不是把它当作传统意义上的几何原子直接照搬，而是把它升级成：

- 可在低分辨率网格上紧凑预测的参数化单元；
- 可显式编码位置、尺度、方向的局部结构单元；
- 可继续承载纹理、频率和相位信息的细节先验单元；
- 可跨分辨率传递到高分辨率恢复过程中的引导单元。

也就是说，我们的 Gaussian 不是普通 feature map，也不是普通 attention map，它更像是一种**可解释、可渲染、可调制的中间结构语言**。

### 4.2 高斯为什么适合 UHD

2D Gaussian 对我们特别有价值，原因有三点：

1. 它天然适合低分辨率紧凑表达。
2. 它比纯卷积特征图更有结构约束，便于跨分辨率传递。
3. 它能把“哪里重要、什么方向重要、什么频率重要”这类信息压缩到少量参数里。

在 UHD 场景下，这种“结构化压缩表达”非常关键，因为我们真正缺的不是更大的 dense 表示，而是**更高效的细节表达方式**。

### 4.3 我们的高斯不是传统纯几何高斯

在当前实现中，每个 Gaussian 原子不是只包含几何参数，而是包含 `10` 个维度的纹理/频率感知参数：

1. `amplitude`
2. `mu_x`
3. `mu_y`
4. `sigma_x`
5. `sigma_y`
6. `theta`
7. `texture_gain`
8. `frequency`
9. `phase`
10. `beta`

这件事非常重要，因为它意味着：

- `mu / sigma / theta` 负责表达局部几何包络；
- `texture_gain / frequency / phase` 负责表达局部纹理载波；
- `beta` 负责表达频谱衰减。

所以我们的 Gaussian 已经不是“模糊的高斯斑点”，而是**纹理/频率感知高斯原子**。

这也是汇报里最值得强调的一句：

> 我们不是把高斯拿来做几何可视化，而是把高斯升级成面向 UHD 细节恢复的参数化先验单元。

## 5. 架构总览

当前最强冻结里程碑 `M03/A_k03` 对应的主干是 `CrossResolutionGaussianRestorer`。它可以概括为一个双分支、跨分辨率、Gaussian-guided 的恢复框架。

整体流程如下：

1. 输入高分辨率图像。
2. 保留一条高分辨率分支，负责细节恢复底座。
3. 同时通过 `pixel_unshuffle` 进入低分辨率分支，做紧凑建模。
4. 在低分辨率分支中提取纹理/频率描述子。
5. 基于低分辨率特征预测 Gaussian 参数场和仿射系数。
6. 由 Gaussian 渲染器生成高分辨率引导 attention。
7. 用高斯引导的 high-pass 增强和低秩仿射调制，作用回高分辨率特征。
8. 由解码器输出 restoration residual，再和输入形成最终恢复结果。

这条链条的关键不是“有两个分支”，而是：

> 低分辨率分支负责学结构化先验，高分辨率分支负责把这些先验转化成真正的细节恢复。

## 6. 高斯在系统里的三个核心作用

### 6.1 作用一：作为低分辨率紧凑参数化表示

低分辨率分支不会直接输出一个大而稠密的高分辨率引导张量，而是先预测：

- Gaussian 参数 `gaussian_params`
- 仿射系数 `affine_coeffs`

这样做的意义是：

1. 把“结构信息”压缩成可控参数，而不是高维稠密特征。
2. 把高分辨率恢复问题拆成“先预测先验，再进行回注”。
3. 为后续的可解释性、模块替换和消融分析提供明确接口。

### 6.2 作用二：作为高分辨率引导图生成器

Gaussian 渲染器会把低分辨率参数场渲染成高分辨率的 `attention_map`。

这一步不是简单上采样，而是显式执行：

1. 定向高斯包络构造；
2. 纹理载波叠加；
3. 频谱衰减控制；
4. 多原子融合。

最终得到的不是普通 feature，而是一个**高分辨率结构化引导图**。

### 6.3 作用三：作为高分辨率特征调制接口

生成 attention 之后，我们并不直接替换高分辨率特征，而是做两步回注：

1. 用 attention 去强调 high-pass 成分；
2. 用低秩 affine modulation 去做通道级调制。

这正是我们架构里“高斯创新点”的核心落地形式。

## 7. 为什么不是普通 attention，而是 Gaussian-guided modulation

这是汇报时很容易被问到的问题。

我们的回答应该非常明确：

### 7.1 我们避免 full-resolution dense attention

普通高分辨率 dense attention 的问题是：

1. 显存成本高；
2. UHD 场景下 token/像素规模太大；
3. 很难在轻量化前提下稳定部署。

而我们的路线是：

- 不直接在高分辨率上学习巨大 attention；
- 先在低分辨率空间预测紧凑高斯参数；
- 再把它渲染成结构化引导。

### 7.2 我们强调的是“高频优先回注”

当前主干里的一个关键操作是：

```text
highpass = highres_feature - avg_pool(highres_feature)
modulated = highres_feature + attention_map * highpass
```

这意味着我们的 Gaussian 引导不是对整张特征图平均施力，而是优先作用于高频残差。

这很符合 UHD restoration 的真实需求，因为真正需要被强调的往往不是低频主体，而是：

- 边缘
- 细纹理
- 模糊边界
- 高频结构

### 7.3 我们进一步使用低秩仿射调制

除了 attention_map，高斯分支还会预测低秩仿射系数，并通过：

```text
features * (1 + scale) + bias
```

去调制高分辨率特征。

这一步的价值是：

1. 不直接预测完整高分辨率仿射参数，保持轻量；
2. 让低分辨率紧凑先验在通道层面对高分辨率恢复继续产生影响；
3. 把“高斯先验”从空间引导进一步拓展到特征调制。

所以更准确地说，我们的高斯不是一个单点模块，而是：

> 从低分辨率参数场，到高分辨率 attention，再到通道级 affine modulation 的整条跨分辨率引导链。

## 8. 里程碑 `M03/A_k03` 已经验证了什么

这里一定要严格区分“当前里程碑已经验证的内容”和“后续新分支正在探索的内容”。

### 8.1 `M03/A_k03` 已验证的主线

当前冻结最强里程碑 `M03/A_k03` 已经验证了以下结论：

1. `V1` 这条“低分辨率紧凑建模 + 高分辨率结构化回注”的主线是可训练、可部署、可长时稳定运行的。
2. 基于纹理/频率感知 Gaussian 参数化的双分支结构，能够在 `UHD_deblur` 上建立当前项目的 strongest frozen baseline。
3. 在 `300` 分钟预算下，`A_k03 final.pt` 取得当前冻结 official full-image test `26.199959289578075 dB`。
4. 相比上一个冻结 baseline `A_i03`，`A_k03` 的 official gain 是 `+0.3493414127052539 dB`。

### 8.2 `M03/A_k03` 这版高斯主线的含义

对汇报来说，最重要的不是只说“我们做到了 26.20 dB”，而是说清楚：

> `M03/A_k03` 证明了高斯主线不是概念设计，而是已经能在真实 UHD deblur 上形成稳定 baseline 的工程化架构。

它不是一次短训偶然涨点，而是一个：

- 有冻结权重；
- 有完整里程碑包；
- 有完整训练日志与评测产物；
- 有明确前后 baseline 对比；
- 可复现实验闭环的正式版本。

## 9. 后续高斯增强分支意味着什么

在 `M03/A_k03` 之后，我们围绕 Gaussian 主线又探索了：

- Gaussian-guided decoder modulation
- Gaussian-guided feature refinement
- edge-weighted reconstruction

这些后续分支的重要意义，不是替代 `M03/A_k03`，而是说明：

1. 高斯作为创新主线是成立的；
2. 我们仍在继续寻找“高斯先验应该作用在哪个层级最有效”；
3. 当前最有希望的趋势，是让高斯更多作用于**feature space**，而不是直接控制最终 RGB residual。

这一点在汇报里可以作为“后续升级路线”去讲，但要明确：

- 这些是**后续增强方向**；
- 当前正式冻结里程碑仍然是 `M03/A_k03`；
- 汇报主线必须以 `M03/A_k03` 为准，而不是把后续 short probe 当成已替代 baseline 的事实。

## 10. 轻量化优势应该怎么讲

我们的轻量化，不是简单指“参数少一点”，而是指整个计算范式更适合 UHD：

1. 关键结构建模发生在低分辨率空间，而不是原图尺度。
2. 高斯参数场是紧凑表达，不是 full-resolution dense feature。
3. 高分辨率侧主要承担结构化回注，而不是全面重建所有全局关系。
4. 低秩 affine modulation 进一步避免了高成本高分辨率参数生成。

因此，汇报时可以把我们的优势概括成：

> 不是靠牺牲建模能力换轻量，而是通过“紧凑参数化 + 结构化回注”重新设计了 UHD restoration 的计算分配方式。

## 11. 当前边界与短板

为了保持汇报可信度，这部分一定要讲。

当前最强里程碑 `M03/A_k03` 虽然是项目内部正式 baseline，但它还存在明确边界：

1. 它仍未跨过当前 `UHD-Blur 90%` 目标阈值 `26.5743 dB`。
2. 它与更强 public reference 之间仍有差距。
3. 它证明了主线可行，但并不意味着高斯增强路径已经完全收敛。

所以更准确的表达不是“我们已经做到了 SOTA 级性能”，而是：

> 我们已经把高斯主线从概念推进成了可冻结、可复现、可对比的最强基线，并正在基于这条主线继续寻找更优的高斯作用点。

## 12. 汇报时建议的核心表述

如果要在口头汇报中用最短的话概括，可以直接讲：

### 版本一：一句话

我们的核心创新不是单独加一个 Gaussian 模块，而是把 2D Gaussian 变成一种面向 UHD 图像复原的跨分辨率结构化先验：先在低分辨率空间紧凑预测纹理/频率感知高斯参数，再通过高分辨率 attention 和低秩仿射调制，把这些先验高效回注到细节恢复过程。

### 版本二：三句话

第一，我们不是在高分辨率上做更重的 dense 建模，而是把复杂结构先压缩到低分辨率 Gaussian 参数场里。
第二，我们的 Gaussian 不是纯几何高斯，而是带方向、频率、相位和谱衰减的纹理感知高斯原子。
第三，我们再把这些高斯先验渲染成高分辨率引导图，并通过 high-pass 增强和低秩仿射调制作用回恢复主干，所以它既轻量，又保留了 UHD 场景需要的细节表达力。

### 版本三：里程碑口径

当前最强冻结里程碑 `M03/A_k03` 证明，这条高斯主线已经不是想法，而是能够在 `UHD_deblur` 上稳定训练、完整评测并形成 official baseline 的真实架构版本。

## 13. 结论

对当前项目而言，最强里程碑 `M03/A_k03` 的真正价值，不只是一个 `26.20 dB` 的数字，而是它把我们的论文主线固定了下来：

1. 问题定义是 UHD restoration 的高效细节恢复。
2. 方法中心是纹理/频率感知 2D Gaussian。
3. 计算策略是低分辨率紧凑建模、高分辨率结构化回注。
4. 关键接口是 Gaussian 渲染、高频引导和低秩仿射调制。

如果汇报里只能保留一个最核心的创新点，那就应该强调：

> 我们的创新不在于“用了高斯”，而在于把高斯从传统几何原子，升级成了服务于超高清图像复原的跨分辨率结构化先验与调制接口。

# 研究方向基线

## 文档定位

这份文档用于正式确立当前项目的研究方向基线。后续讨论算法、实验、数据集、消融和论文写作时，默认以本文件为准，而不是以临时 brainstorming、伪代码草稿或单次对话结论为准。

## 投稿目标

- 目标期刊：`IEEE Transactions on Image Processing (TIP)`
- 项目主题：`超高清图像复原`
- 当前阶段目标：先明确研究问题、论文主线和创新边界，不提前锁死最终实现细节

## 一句话方向定义

我们要研究的是一种**面向超高清图像复原的跨分辨率纹理/频率感知 2D Gaussian 引导框架**：
在低分辨率空间建立更紧凑的 2D Gaussian 参数化表示，再将其生成的结构化引导通过仿射映射或仿射调制方式作用回高分辨率图像或特征，从而在控制参数量和显存开销的同时提升 UHD 场景下的细节恢复能力。

## 正式问题定义

本项目聚焦的问题不是“普通图像复原是否还能继续涨点”，而是：

> 在超高清图像复原任务中，如何避免直接在原始分辨率上进行高成本密集建模，同时又不过度牺牲高频纹理、局部结构和精细细节的恢复能力？

围绕这个问题，我们当前认可的核心矛盾是：

1. UHD 图像像素数极高，直接全分辨率建模代价很大；
2. 常规下采样和低通型恢复模块容易削弱高频细节；
3. 标准 2D Gaussian 参数表达能力有限，难以直接覆盖丰富纹理模式；
4. 因而需要一种**低分辨率紧凑建模 + 高分辨率有效回注**的中间路线。

## 当前主线假设

本项目当前的主线假设包括：

### 假设 1：低分辨率空间更适合做紧凑参数建模

相比直接在原图尺度建立密集高维表示，在较低分辨率空间预测结构化参数，更有希望在 UHD 条件下获得更好的复杂度-性能平衡。

### 假设 2：2D Gaussian 可以从“几何包络”扩展到“纹理感知原子”

2D Gaussian 不应只表达位置、形状、尺度等传统参数，而应进一步具备对局部纹理、方向性、频率特征或高频响应的感知能力。

### 假设 3：高分辨率恢复不一定需要 dense attention

UHD 场景下，不必显式构建巨大且稠密的高分辨率注意力张量。更可行的方向是：
用低分辨率预测出的紧凑参数生成结构化引导，再通过高分辨率局部调制完成恢复。

### 假设 4：仿射作用机制是连接低分辨率建模与高分辨率恢复的关键接口

低分辨率参数场与原图之间不能只是简单上采样，而应通过某种仿射映射、仿射调制或局部线性变换机制，把低分辨率学到的结构化信息高效作用到原图或原图特征。

## 论文主线应该讲什么

如果后续形成 TIP 论文，当前最适合的论文主线不是“我们又做了一个新的 restoration backbone”，而是：

1. `UHD 图像复原`下的建模与计算矛盾；
2. 传统 dense high-resolution restoration 在参数量和显存上的局限；
3. 纹理/频率感知 2D Gaussian 参数化的必要性；
4. 低分辨率参数预测与高分辨率仿射回注的整体框架；
5. 为什么这种结构比直接做高分辨率 dense attention 更适合 UHD。

## 当前认可的潜在论文贡献形态

在不提前夸大贡献的前提下，当前可以保留为论文贡献候选的点包括：

### 贡献候选 1：新的问题建模方式

把 UHD 图像复原表述为一种“低分辨率紧凑参数场预测 + 高分辨率结构化回注”的问题，而不是传统的纯 backbone 堆叠问题。

### 贡献候选 2：纹理/频率感知 2D Gaussian 参数化

让局部 Gaussian 原子不仅表达空间包络，也表达纹理或频率相关属性，用于 UHD 细节恢复。

### 贡献候选 3：跨分辨率高斯引导机制

在低分辨率空间生成高斯参数或引导张量，再通过仿射映射作用到原始分辨率图像/特征上。

### 贡献候选 4：面向 UHD 的高效调制范式

避免 full-resolution dense attention，转而使用紧凑参数场 + 局部调制/仿射作用，以提高实际可部署性。

# 数据集文件夹只读审计

## 审计对象

- 数据目录：`/root/autodl-tmp/2D_Gaussian_Dataset`
- 审计方式：**只读检查**
- 审计目标：判断当前已经下载到的数据内容是否与目标数据集方向一致，以及是否已达到“可直接使用”的状态

## 审计原则

- 不移动、不解压、不修改目标目录中的任何文件
- 只检查目录结构、文件命名、归档内部路径、样例图像尺寸和文件完整性线索
- 判断重点是“内容方向是否正确、是否足以构成数据集”，而不是“文件能否双击打开”

## 当前目录概览

当前在 `/root/autodl-tmp/2D_Gaussian_Dataset` 下看到的主要内容有：

- `4KDehaze`
- `8K`
- `LOL-v1`
- `LOL-v2`

## 分项判断

### 1. LOL-v1

当前结构：

- `LOL-v1/our485/input`
- `LOL-v1/our485/gt`
- `LOL-v1/eval15/input`
- `LOL-v1/eval15/gt`

判断：

- **目录结构是对的**
- 但目前目录里 **没有任何实际图像文件**
- 因此它现在只能算“空壳目录”，**暂时不能直接使用**

结论：

- `LOL-v1` 的组织方式符合公开数据集习惯
- 但当前下载内容 **不完整**

### 2. LOL-v2

当前结构：

- `LOL-v2/Train/input`
- `LOL-v2/Train/gt`
- `LOL-v2/Test/input`
- `LOL-v2/Test/gt`

判断：

- **目录结构也是对的**
- 但与 `LOL-v1` 一样，目前 **没有实际图像文件**
- 因此当前 **暂时不能直接使用**

结论：

- `LOL-v2` 的目录命名正确
- 但当前下载内容 **仍不完整**

### 3. 4KDehaze

当前内容：

- `4KDehazing.part01.rar` 到 `4KDehazing.part12.rar`
- `4KDehazing.pth`

只读核对结果：

- 分卷压缩包命名合理，像一个大体量数据集归档
- 归档内部存在大量：
  `4KDehazing/groundtrues/000000.jpg`
  这样的图像文件
- 抽样核对了 `000000.jpg` 的图像信息：
  - `JPEG`
  - `RGB`
  - 分辨率为 `3840×2160`
- 归档内部当前可见的一级子目录只有：
  - `groundtrues`
- 归档文件总条目数约为：
  - `2041`
- 目录里额外还有一个：
  - `4KDehazing.pth`
  这明显是**模型权重文件**，不是数据样本

判断：

- 从内容方向看，`4KDehaze` **确实是在下载 UHD 去雾相关数据**
- 而且样例图像确实是 `3840×2160`，这一点是对的
- 但当前暴露出来的内容 **只有 ground truth 清晰图**
- 没有看到与之成对的 hazy 图、标注文件或明确的 train/test 划分
- 另外，条目数 `2041` 与我们从论文里整理出的 `UHD-Haze` 统计
  `2290 train + 230 test = 2520`
  **并不一致**

结论：

- `4KDehaze` **内容方向基本正确**
- 但**不能确认它已经是完整可训练/可评测的成对去雾数据集**
- 更像是：
  - 原始清晰 4K 图像集合，或
  - UHD 去雾数据的一部分，或
  - 与目标 benchmark 相关但尚不完整的版本

### 4. 8K

当前内容：

- `8K.z01`
- `8K.z02`
- `8K.z03`
- `8K.z04`

只读核对结果：

- `file` 命令显示 `8K.z01` 是：
  `Zip multi-volume archive`
- 但目录中 **没有主归档文件**，例如：
  - `8K.zip`
  - 或其他尾卷主文件
- 因而当前 **无法安全列出归档内部内容**

判断：

- 这说明 `8K` 这套数据 **还处于未完成或未拼齐状态**
- 目前还不能确认其中具体是什么数据
- 也不能判断是否与我们的目标任务完全匹配

结论：

- `8K` 当前 **不能直接使用**
- 也**无法确认内容是否完全正确**
- 需要等主归档文件完整出现之后再继续核查

## 综合结论

截至当前审计时点：

1. `LOL-v1`：目录结构对，但内容为空，**不可用**
2. `LOL-v2`：目录结构对，但内容为空，**不可用**
3. `4KDehaze`：方向对、样例分辨率对，但目前只看到 `groundtrues`，且统计与论文中的 `UHD-Haze` benchmark 不完全对齐，**暂不能判定为完整可用的目标数据集**
4. `8K`：分卷压缩尚未齐全，**不可用且无法确认内容**

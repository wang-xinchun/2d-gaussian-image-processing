# 项目方向说明

## 论文目标

- 目标投稿：`IEEE Transactions on Image Processing (TIP)`
- 研究主题：`超高清图像复原`

## 我们当前明确的核心方向

我们要做的不是普通分辨率下的图像复原，而是面向**超高清图像**场景，研究一种**参数更可控、同时对纹理和细节更敏感的 2D Gaussian 引导式复原框架**。

核心出发点是：

1. 超高清图像的像素数量非常大，如果直接在原始分辨率上做 2D Gaussian 建模，参数量会非常高。
2. 现有 2D Gaussian 表达如果只保留常规参数，可能不足以刻画我们真正关心的高频纹理、局部结构和细节模式。
3. 因此，我们希望在保留 2D Gaussian 表达优势的同时，引入**纹理/频率感知能力**，并通过**跨分辨率引导**的方式，把低分辨率空间里学到的结构信息作用回原图。

## 高层思路

当前项目的大体思路可以概括为：

- 先对输入图像进行下采样；
- 在较低分辨率空间中，使用一个改进版本的、带有**纹理频率感知能力**的 2D Gaussian 表达进行建模；
- 该过程输出的不只是普通特征，而是一个能够反映局部结构、纹理强度和频率分布的**注意力张量**；
- 再将这个注意力张量通过某种**仿射变化/仿射映射方式**作用到原始分辨率图像上；
- 最终形成一种“**低分辨率参数建模，高分辨率细节引导**”的复原范式。

## 这个方向想解决的核心矛盾

这条路线本质上是在解决以下矛盾：

- 一方面，超高清图像复原需要足够强的局部细节表达能力；
- 另一方面，直接在原图尺度上建立密集的 2D Gaussian 参数表示，代价过高；
- 所以我们希望通过**降采样空间中的紧凑建模**，换取**原图空间中的高质量调制与恢复**。

## 我们当前认可的关键概念

现阶段已经明确、后续方案都应围绕展开的关键词包括：

- 超高清图像复原
- 2D Gaussian 表达
- 参数量控制
- 纹理参数扩展
- 频率感知
- 低分辨率建模
- 高分辨率注意力回注
- 仿射映射/仿射调制

## 当前阶段不提前锁死的内容

为了保留研究空间，下面这些内容目前**先不做具体落实**，后续再展开：

- 具体采用哪一种 2D Gaussian 参数化形式
- 纹理参数到底如何定义
- 频率感知模块用什么网络结构实现
- 注意力张量的精确定义和维度设计
- 仿射变化是在坐标空间、特征空间还是参数空间进行
- 最终先做哪一个复原子任务作为主实验入口

## 一句话版本

我们的项目方向可以概括为：

> 面向 TIP 论文投稿，研究一种用于超高清图像复原的纹理/频率感知 2D Gaussian 引导框架，在低分辨率空间进行更紧凑的结构建模，并通过仿射映射得到可作用于原图的注意力张量，从而兼顾参数效率与高分辨率细节恢复能力。

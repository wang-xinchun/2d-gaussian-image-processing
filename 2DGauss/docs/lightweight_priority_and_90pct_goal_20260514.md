# 轻量化优先与 90% 性能门槛（2026-05-14）

## 文档目的

这份文档用于正式记录当前项目新增的顶层约束：

1. 项目的核心辨识度是 `2D Gaussian` 带来的 **轻量化** 与 **UHD 友好**；
2. 因此后续方法演化不能为了追绝对 `SOTA` 而放弃整体轻量化；
3. 虽然“所有指标都追平最强 SOTA”几乎不现实，但至少要把正式结果推进到 **公开强参考值的 90% 以上**。

这不是新的训练设计包，而是后续所有实验分支、模板升级与论文叙事都必须遵守的目标约束。

## 一句话原则

> 我们要做的是“尽可能轻量、但性能不能太弱”的 UHD 复原方法，而不是“为了涨点把主线改成更重的大模型”。

## 为什么这是核心约束

当前项目的正式研究方向已经明确：

- 主线是 `低分辨率紧凑建模 + 高分辨率结构化回注`
- 核心媒介是 `纹理/频率感知 2D Gaussian`
- 目标优势之一就是避免 full-resolution dense 建模带来的巨大计算与显存开销

如果为了追点而把主体逐步改写成：

- 明显更重的通用 backbone
- 与 Gaussian 弱相关的大型重建网络
- 需要巨大参数量或显著更高推理代价的替代方案

那么即使数值上涨，也会损伤项目最重要的辨识度。

因此，后续所有方案都要遵守：

- `Gaussian` 不是装饰性模块，而是轻量化主线的一部分；
- 轻量化不是附属优点，而是论文价值的一部分；
- 新设计必须解释它如何保留或增强这条轻量化叙事。

## “90% 性能”如何在项目里定义

这里需要明确：

- `PSNR` 不是线性百分比指标；
- 因而“90% 性能”不能被解释成严格物理意义上的“恢复质量达到对方 90%”；
- 但为了项目管理与实验决策，我们需要一个清晰、统一、可执行的门槛。

因此当前采用下面这条 **工程/项目门槛定义**：

> 在相同 benchmark、相同 official evaluation protocol 下，若本地结果满足
> `PSNR >= 0.9 × 当前公开强参考值`，则视为“达到该任务线的 90% 性能门槛”。

同时保留下面这条 **科学汇报口径**：

- 正式汇报时仍优先报告 `绝对 PSNR / SSIM / LPIPS`；
- “90% 门槛”只用于内部目标管理与路线筛选，不替代正式学术比较。

## 当前三条 UHD 主线的 90% PSNR 门槛

基于当前本地统一 benchmark 表中的公开强参考值：

| 任务 | 当前公开强参考值 | 90% 门槛 |
|---|---:|---:|
| `UHD-LL` | `27.159` | `24.4431` |
| `UHD-Haze` | `22.725` | `20.4525` |
| `UHD-Blur` | `29.527` | `26.5743` |

说明：

- `UHD-LL` 当前公开强参考值取 `UHDPromer = 27.159 dB`
- `UHD-Haze` 当前公开强参考值取 `UHDPromer = 22.725 dB`
- `UHD-Blur` 当前公开强参考值取 `UHDPromer = 29.527 dB`

如果后续我们确认有更新、且可核实的更强公开结果，应同步刷新这些门槛。

- 因此暂时不能把它直接视为 `UHD-LL` 90% 门槛达成证据；
- 后续必须补齐严格 `UHD-LL` official 结果，才能判断是否过线。

## 由此导出的项目策略

### 1. 绝对 SOTA 不再作为短期硬目标

短期目标不是：

- 必须追平最强公开方法

而是：

- 在保持整体轻量化叙事成立的前提下，把 official 结果推进到 `90% 门槛` 以上。

### 2. 新方法不能以明显增重为代价换点

若某条方案需要：

- 大幅提高主体参数量
- 显著增加高分辨率 dense 计算
- 让 `Gaussian` 在整体里退化成边缘小插件

则默认不符合当前主线，即使可能涨点，也不是优先方向。

### 3. 更合适的升级方式是“轻量模板升级”，不是“重模型替换”

后续更值得尝试的是：

- 更强但仍轻量的 train-inference consistency 模板
- 更有效的高低分辨率信息交互
- 更强但受控的高分辨率 reconstruction branch
- 必要时加入外挂式轻量先验增强

而不是：

- 直接转向更重的大 backbone 主体
- 直接把项目改造成另一篇 restoration 架构论文

## 当前结论

当前项目的现实目标已经明确调整为：

1. 保住轻量化主线；
2. 把三条 UHD 主线的 official 结果尽可能推进到公开强参考值的 `90%` 以上；
3. 在满足这个门槛后，再判断是否有必要进一步冲击更高绝对性能。

这意味着：

- 以后所有实验设计都必须同时回答两个问题：
  - 它能不能涨点？
  - 它会不会破坏轻量化主线？

如果第二个问题答不好，那么即使第一个问题是“可能涨点”，也不应作为优先方案。
